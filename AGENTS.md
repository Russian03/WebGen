# WebGen · instrucciones para asistentes

- Monorepo npm workspaces: una web por carpeta en `webs/`, plantilla en
  `templates/base`, paquetes compartidos en `packages/`.
- Comandos: ver `README.md` (`make dev WEB=…`, `make build-all`).
- Repositorio público: nunca escribir claves secretas en el código.
- Astro: https://docs.astro.build
